# Security and private data

Never post private media, credentials, native caches, personal paths or unredacted logs in public issues. Inspect plans before running local tools.

Use GitHub private vulnerability reporting when enabled. If unavailable, request a private contact channel in an issue without exploit details or private data.

The release builder allowlist and pattern checks are limited safeguards, not proof that arbitrary input is publishable. The core does not upload media or control external publishing.
