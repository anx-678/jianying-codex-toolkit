# 常见修订与证据

- 转场生硬：先看前后镜头要表达的联系，调整顺序、源入出点、主体位置与停留，再考虑效果。技术界面长叠化常导致不可读。
- 图片抖：隔离照片关键帧、源视频抖动、转场重影与重采样。先取消无必要的微幅缩放，确认当前版本再验证，不能用上一版检查覆盖新版。
- 混合画幅：先保住主体和信息关系；不要用拉伸填屏。完整界面＋同源同步局部可以预合成，注明内部不可拆编辑。
- 品牌或结束突兀：找动作、观点与音乐乐句的收束，检查前后亮度和遮罩连续。旅行、教程、访谈不必硬加企业署名式落版。
- 访谈碎：先保完整观点，再用相关 B-roll 覆盖画面切口；听到剪口再补环境底声，不拼造讲话意思。
- 教程看不懂：核对缺失前提、步骤依赖、完成反馈和等待条件；延长关键步骤优先于加动效。
- 音乐卡点：实际试听候选区间，标记展开、变化、人声句尾和结束。信号分析只提供候选，不独自证明重拍相位和听感。

每轮保留旧版，优先处理最影响理解的两三项。机器通过后继续实际画面和听感审片；没有新问题则停止无依据重渲染。依次记录草稿生成、原生打开、保存重开、原生导出、技术解码、视觉审片、听感审片和发布范围。
