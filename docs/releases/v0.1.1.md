# v0.1.1 — First public release

Codex × 剪映多场景本地工具包：Skill负责制作判断，CLI执行可核验操作，剪映负责原生编辑与导出。

## 下载哪个文件

- `jianying-codex-toolkit-v0.1.1.zip`：完整源码、离线HTML手册、六场景示例、测试与维护工具。
- `jianying-codex-toolkit-skill-v0.1.1.zip`：自包含Skill，含脚本、策略、参考与MIT许可。解压到新技能目录，不覆盖现有安装。
- `SHA256SUMS.txt` 与 `release-manifest.json`：下载校验、版本和大小信息。

## 能力与边界

提供六场景策略、素材盘点、时间线校验、基础预览和Windows基础草稿。原声默认保留，不支持的效果报错，输出不覆盖。

复杂效果、自动语义选片、可靠J/L编辑、自动原生导出未实现。Mac原生剪映未实测；跨平台核心以CI实际结果为准。程序预览不冒充剪映导出，合成测试不代替真实素材审美或听感。

## 安装

完整包解压后运行 `uv sync --locked`、`uv run python toolkit.py doctor`。预览另需FFmpeg；Windows原生草稿使用 `uv sync --locked --extra draft`。

原创代码与文档采用MIT。第三方依赖各遵守其许可。不含客户素材、歌曲、私人路径和第三方二进制。
