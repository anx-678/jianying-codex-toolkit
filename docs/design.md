# v0.1 设计与实施范围

2026-10-21。目标：把单项目经验转成可运行的多场景本地工具包，不把“泛化”误写成一个固定模板适用所有视频。

架构为场景策略 → 人工/AI 看素材并选片 → JSON 计划 → 校验 → 独立预览/草稿适配器 → 原生审片与导出。Skill 单独可安装，包含全部核心脚本、策略与参考；仓库提供开发、测试和学习入口。没有常驻服务、上传或平台发布。

选择 Skill＋CLI 是因为纯提示词缺少确定性执行，直接 MCP 会过早绑定环境。v0.1 不实现任意效果、自动转写、自动语义选片、音乐库抓取、J/L cut编辑器、自动剪映导出或工程回读；保留明确的扩展位置。

## 实施与验证

- 核心失败用例先行：源区间、路径、连续帧、原声策略、重复ID与不支持效果。
- 六场景分别有策略与合成计划示例，不锁定曲目、时长、画幅与客户身份。
- 生成自己的合成媒体，运行计划、预览、基础草稿与包内 Skill 检查。
- 原生打开/导出、真实听感和 Mac 真机另行记录；CI配置不当成CI运行结果。
- 保留旧工具包和旧Skill，新增通用Skill，避免替换已有项目流程。
